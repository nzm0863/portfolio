# Portfolio Site

Web制作とIoT開発の実績をまとめたポートフォリオサイトです。

## URL
https://www.nnzzm.com/

## 主な掲載内容

- TaskFlow（React / TypeScript / PHP）
- 歯科医院向けサイト制作
- WordPressテーマ化ポートフォリオ
- ESP32・Raspberry Piを活用したIoT開発
- GitHub・YouTubeへのリンク

## 使用技術

### Frontend
- React
- TypeScript
- Vite

### backend
- PHP
- MySQL

### Design
- Figma
- Canva

### CMS
- WordPress
- PHP

### IoT
- ESP32
- Arduino IDE
- Raspberry Pi

## こだわった点

- Web制作だけでなくIoT開発の実績も掲載し、自身の強みを伝えられる構成にした
- GitHubやYouTubeへの導線を設け、制作過程やソースコードを確認できるようにした
- WordPressテーマ化作品を掲載し、CMS対応経験もアピールできるようにした

## 開発環境

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
